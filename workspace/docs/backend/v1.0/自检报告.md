### 7. 已知问题和限制

1. **AI服务依赖**: AI出题、追问、报告生成依赖于AI网关服务(ai-gateway)可用
2. **API Key配置**: AI网关需要配置有效的AI服务商API Key才能正常工作
3. **WebSocket认证**: WebSocket连接使用token参数进行简单认证，生产环境建议使用更安全的方案
4. **默认题目**: 当AI服务不可用时，系统会返回预设的默认题目确保面试流程可继续
