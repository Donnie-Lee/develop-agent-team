## 4. 技术实现

### 4.1 JWT认证

- AccessToken: 15分钟有效期
- RefreshToken: 7天有效期
- Token黑名单: Redis存储

### 4.2 验证码

- 存储: Redis
- 有效期: 5分钟
- 格式: 6位数字

### 4.3 文件上传

- 支持格式: PDF, Word (.doc, .docx)
- 文件大小限制: 10MB
- 存储: 阿里云OSS

### 4.4 AI简历解析

- 异步处理模式
- 解析状态: 0未解析, 1解析中, 2已解析
- 结果存储: JSON格式

## 6. 依赖环境

### 6.1 必需服务

- PostgreSQL 15+
- Redis 6+
- Nacos (服务发现)
- 阿里云OSS (文件存储)
- 阿里云SMS (短信服务)

### 6.2 环境变量

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| DB_HOST | 数据库主机 | localhost |
| DB_PORT | 数据库端口 | 5432 |
| DB_USERNAME | 数据库用户名 | postgres |
| DB_PASSWORD | 数据库密码 | postgres |
| REDIS_HOST | Redis主机 | localhost |
| REDIS_PORT | Redis端口 | 6379 |
| JWT_SECRET | JWT密钥 | (需配置) |

| OSS_ENDPOINT | OSS endpoint | - |
