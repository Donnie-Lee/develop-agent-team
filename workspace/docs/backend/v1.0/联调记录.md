## P1 Bug 修复状态

### Bug 1: 编译器参数保留配置缺失 (question-service) - ✅ 已修复

**问题描述**
MyBatis-Plus 的 LambdaQueryWrapper 使用 `Question::getCreatedAt` 等方法引用时，需要通过反射获取属性名。但编译器未配置保留参数名称，导致反射失败。

**错误信息**
```
Name for argument of type [java.lang.Integer] not specified, and parameter name information not available via reflection.
Ensure that the compiler uses the '-parameters' flag.
```

**修复方案**
在 question-service 的 `pom.xml` 中配置 maven-compiler-plugin 添加 `<parameters>true</parameters>`:

```xml
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-compiler-plugin</artifactId>
    <version>3.11.0</version>
    <configuration>
        <source>17</source>
        <target>17</target>
        <parameters>true</parameters>  <!-- 已添加 -->
        <annotationProcessorPaths>
            ...
        </annotationProcessorPaths>
    </configuration>
</plugin>
```

**修复文件**
- `/workspace/backend/question-service/pom.xml`

**受影响服务**
- question-service (已修复)
- 其他使用 MyBatis-Plus LambdaQueryWrapper 的服务需检查

### Bug 3: 面试问题接口路径不匹配 - ✅ 已修复

**问题描述**
- 前端调用: `GET /api/v1/interview/{id}/questions`
- 后端原接口: `GET /api/v1/interview/session/{sessionId}/questions`（需要 sessionId）

**修复方案**
添加新接口 `GET /api/v1/interview/{id}/questions`，通过 interviewId 获取问题列表。

**修复文件**
- `/workspace/backend/interview-service/src/main/java/com/interviewai/interview/controller/InterviewController.java`
- `/workspace/backend/interview-service/src/main/java/com/interviewai/interview/service/InterviewService.java`

**新增接口**
```java
@GetMapping("/{id}/questions")
public Result<List<QuestionResponse>> getInterviewQuestions(
        @RequestHeader("Authorization") String authHeader,
        @PathVariable("id") Long id) {
    Long userId = getUserIdFromToken(authHeader);
    List<QuestionResponse> responses = interviewService.getQuestionsByInterviewId(id, userId);
    return Result.success(responses);
}
```
