## 接口详情

### 用户模块

#### 1. 发送验证码
```
POST /api/v1/user/send-code
Content-Type: application/json

请求参数：
{
    "phone": "13800138000",
    "type": "login"
}

响应：
{
    "code": 0,
    "message": "success",
    "data": { "expiresIn": 300 }
}
```

#### 2. 手机号登录
```
POST /api/v1/user/login-phone
Content-Type: application/json

请求参数：
{
    "phone": "13800138000",
    "code": "123456"
}

响应：
{
    "code": 0,
    "message": "success",
    "data": {
        "accessToken": "eyJhbGci...",
        "refreshToken": "eyJhbGci...",
        "expiresIn": 900,
        "userInfo": { ... }
    }
}
```

#### 3. 获取用户信息
```
GET /api/v1/user/info
Authorization: Bearer {accessToken}

响应：
{
    "code": 0,
    "message": "success",
    "data": {
        "id": 1,
        "phone": "13800138000",
        "nickname": "用户3800",
        "avatarUrl": null,
        "memberLevel": 0
    }
}
```

#### 4. 更新用户信息
```
PUT /api/v1/user/info
Authorization: Bearer {accessToken}
Content-Type: application/json

请求参数：
{
    "nickname": "新昵称",
    "avatarUrl": "https://example.com/avatar.jpg"
}

响应：
{
    "code": 0,
    "message": "success",
    "data": { ... }
}
```

### 简历模块

#### 5. 获取简历列表
```
GET /api/v1/resumes
Authorization: Bearer {accessToken}

响应：
{
    "code": 0,
    "message": "success",
    "data": [
        {
            "id": 1,
            "title": "我的简历",
            "isDefault": true,
            "updatedAt": "2026-04-03T10:00:00"
        }
    ]
}
```

#### 6. 创建简历
```
POST /api/v1/resumes
Authorization: Bearer {accessToken}
Content-Type: application/json

请求参数：
{
    "title": "我的简历"
}

响应：
{
    "code": 0,
    "message": "success",
    "data": {
        "id": 1,
        "title": "我的简历",
        "isDefault": true,
        "parseStatus": 0,
        "sections": [],
        "updatedAt": "2026-04-03T10:00:00"
    }
}
```

#### 7. 获取简历详情
```
GET /api/v1/resumes/{id}
Authorization: Bearer {accessToken}

响应：
{
    "code": 0,
    "message": "success",
    "data": {
        "id": 1,
        "title": "我的简历",
        "isDefault": true,
        "parseStatus": 2,
        "parseResult": { ... },
        "sections": [ ... ],
        "updatedAt": "2026-04-03T10:00:00"
    }
}
```

#### 8. 更新简历
```
PUT /api/v1/resumes/{id}
Authorization: Bearer {accessToken}
Content-Type: application/json

请求参数：
{
    "title": "更新后的简历",
    "sections": [ ... ]
}

响应：
{
    "code": 0,
    "message": "success",
    "data": { ... }
}
```

#### 9. 删除简历
```
DELETE /api/v1/resumes/{id}
Authorization: Bearer {accessToken}

响应：
{
    "code": 0,
    "message": "success"
}
```

#### 10. 上传简历文件
```
POST /api/v1/resumes/upload
Authorization: Bearer {accessToken}
Content-Type: multipart/form-data

请求参数：
- file: 简历文件 (必填，PDF/Word)
- resumeId: 关联简历ID (可选)

响应：
{
    "code": 0,
    "message": "success",
    "data": {
        "fileUrl": "https://oss.example.com/resumes/xxx.pdf",
        "fileName": "xxx.pdf"
    }
}
```

#### 11. 解析简历
```
POST /api/v1/resumes/{id}/parse
Authorization: Bearer {accessToken}

响应：
{
    "code": 0,
    "message": "success",
    "data": {
        "parseStatus": 0,
        "parseResult": null
    }
}
```

#### 12. 获取简历分析报告
```
GET /api/v1/resumes/{id}/analyze
Authorization: Bearer {accessToken}

响应：
{
    "code": 0,
    "message": "success",
    "data": {
        "completeness": 75,
        "keywords": ["Java", "Spring Boot"],
        "competitiveness": 72,
        "highlights": [ ... ],
        "risks": [ ... ]
    }
}
```

#### 13. 获取优化建议
```
GET /api/v1/resumes/{id}/suggestions
Authorization: Bearer {accessToken}

响应：
{
    "code": 0,
    "message": "success",
    "data": {
        "contentSuggestions": [ ... ],
        "structureSuggestions": [ ... ],
        "keywordSuggestions": [ ... ]
    }
}
```

## 统一响应格式

```json
{
    "code": 0,
    "message": "success",
    "data": {},
    "timestamp": 1699999999999
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码，0为成功 |
| message | string | 状态信息 |
| data | object | 响应数据 |
| timestamp | long | 时间戳 |

## 错误码

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 1001 | 参数错误 |
| 2001 | Token无效 |
| 2002 | Token过期 |
| 3001 | 资源不存在 |
| 3002 | 资源已存在 |
| 4011 | 请求头缺失: Authorization |
| 5001 | 系统内部错误 |
