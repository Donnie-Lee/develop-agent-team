## 1. 接口规范

### 1.1 基础规范

| 规范 | 说明 |
|------|------|
| 协议 | HTTP/HTTPS |
| 编码 | UTF-8 |
| 内容类型 | application/json |
| 认证方式 | JWT Bearer Token |

### 1.2 统一响应格式

```json
{
    "code": 0,
    "message": "success",
    "data": {},
    "timestamp": 1699999999999,
    "traceId": "xxx"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码，0为成功 |
| message | string | 状态信息 |
| data | object | 响应数据 |
| timestamp | long | 时间戳 |
| traceId | string | 追踪ID |

### 1.3 错误码

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 1001 | 参数错误 |
| 2001 | Token无效 |
| 2002 | Token过期 |
| 3001 | 资源不存在 |
| 3002 | 资源已存在 |
| 3003 | 业务状态错误 |
| 4001 | 外部服务不可用 |
| 5001 | 系统内部错误 |

## 6. AI网关

### 6.1 聊天接口

```
POST /api/v1/ai/chat
Content-Type: application/json
```

**请求参数：**

```json
{
    "message": "用户输入",
    "provider": "aliyun",
    "model": "qwen-turbo",
    "temperature": 0.7,
    "maxTokens": 2000,
    "history": [
        {"role": "user", "content": "之前的问题"},
        {"role": "assistant", "content": "之前的回答"}
    ]
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| message | string | 是 | 用户消息 |
| provider | string | 否 | AI提供商: aliyun/zhipu，默认aliyun |
| model | string | 否 | 模型名称 |
| temperature | double | 否 | 温度参数，默认0.7 |
| maxTokens | int | 否 | 最大token数 |
| conversationId | string | 否 | 会话ID |
| history | array | 否 | 历史消息 |

**响应：**

```json
{
    "code": 0,
    "message": "success",
    "data": {
        "conversationId": "xxx",
        "provider": "aliyun",
        "content": "AI回复内容",
        "promptTokens": 100,
        "completionTokens": 200,
        "usageTokens": 300,
        "finishReason": "stop"
    },
    "timestamp": 1699999999999
}
```
