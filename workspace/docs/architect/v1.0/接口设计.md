## 1. 接口规范

### 1.1 RESTful API 设计规范

| 规范 | 说明 |
|------|------|
| **URL格式** | `/api/v1/{module}/{resource}` |
| **HTTP方法** | GET(查询), POST(创建), PUT(更新), DELETE(删除) |
| **认证方式** | JWT Bearer Token |
| **请求格式** | `Content-Type: application/json` |
| **响应格式** | 统一响应结构 |

### 1.2 统一响应结构

```json
{
    "code": 0,
    "message": "success",
    "data": { },
    "timestamp": 1699999999999,
    "traceId": "xxx"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码，0为成功 |
| message | string | 状态信息 |
| data | object | 响应数据 |
| timestamp | long | 时间戳 |
| traceId | string | 追踪ID |

### 1.3 错误码规范

| 错误码区间 | 说明 |
|------------|------|
| 0 | 成功 |
| 1000-1999 | 通用错误 |
| 2000-2999 | 用户认证错误 |
| 3000-3999 | 业务逻辑错误 |
| 4000-4999 | 外部服务错误 |
| 5000-5999 | 系统内部错误 |

### 1.4 详细错误码

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| 0 | 成功 | - |
| 1001 | 参数错误 | 检查请求参数 |
| 1002 | 缺少必填参数 | 补充必填参数 |
| 1003 | 参数格式错误 | 检查参数格式 |
| 2001 | Token无效 | 重新登录 |
| 2002 | Token过期 | 刷新Token |
| 2003 | 无访问权限 | 申请权限 |
| 3001 | 资源不存在 | 检查资源ID |
| 3002 | 资源已存在 | 检查重复创建 |
| 3003 | 业务状态错误 | 检查业务状态 |
| 4001 | AI服务不可用 | 稍后重试 |
| 4002 | 支付服务不可用 | 稍后重试 |
| 5001 | 系统内部错误 | 联系技术支持 |

## 2. 用户模块接口

### 2.1 发送验证码

```
POST /api/v1/user/send-code
```

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| phone | string | 是 | 手机号 |
| type | string | 是 | 验证码类型：login/register |

**请求示例**：

```json
{
    "phone": "13800138000",
    "type": "login"
}
```

**响应示例**：

```json
{
    "code": 0,
    "message": "success",
    "data": {
        "expiresIn": 300
    }
}
```

### 2.2 手机号登录

```
POST /api/v1/user/login-phone
```

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| phone | string | 是 | 手机号 |
| code | string | 是 | 验证码 |

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| accessToken | string | 访问令牌 |
| refreshToken | string | 刷新令牌 |
| expiresIn | int | 过期时间(秒) |
| userInfo | object | 用户信息 |

### 2.3 退出登录

## 7. AI对话流式接口

### 7.1 面试对话流式接口

```
POST /api/v1/interview/chat-stream
Authorization: Bearer {token}
Content-Type: application/json
```

**请求体**：

```json
{
    "interviewId": "12345",
    "message": "用户回答内容",
    "mode": "voice",
    "audioData": "base64编码的音频数据(可选)"
}
```

**响应**：SSE流式响应

```
data: {"type": "question", "content": "问题内容"}
data: {"type": "feedback", "content": "即时反馈"}
data: {"type": "score", "score": 85}
data: {"type": "done", "nextQuestion": true}
```

| 事件类型 | 说明 |
|----------|------|
| question | AI提问 |
| feedback | 即时反馈 |
| score | 回答评分 |
| done | 当前问题结束 |

### 7.2 WebSocket连接

```
ws://api.example.com/ws/interview/{interviewId}
Authorization: Bearer {token}
```

**服务端推送消息格式**：

```json
{
    "type": "question",
    "data": {
        "questionId": "123",
        "content": "请介绍一下你在项目中的角色",
        "type": "practical"
    }
}
```

**客户端发送消息格式**：

```json
{
    "type": "answer",
    "data": {
        "content": "在我的项目中，我主要负责...",
        "audioData": "base64..."
    }
}
```

## 8. 接口版本管理

### 8.1 版本控制策略

| 策略 | 说明 |
|------|------|
| URL版本 | `/api/v1/` `/api/v2/` |

| 升级类型 | 影响 | 说明 |
