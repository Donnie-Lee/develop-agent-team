## 1. 数据库选型

### 1.1 数据库选型理由

| 数据库 | 选型 | 理由分析 |
|--------|------|----------|
| **PostgreSQL** | ✅ 采用 | 支持JSON类型（简历半结构化数据）；全文检索；PostGIS地理信息扩展；MySQL相比更符合SQL标准 |
| **Redis Cluster** | ✅ 采用 | K-V缓存性能极高；支持集群模式高可用；支持多种数据结构；Spring Boot原生支持 |
| **Elasticsearch** | ✅ 采用 | 题库全文检索；简历关键词搜索；聚合统计面试数据；Kibana可视化 |
| **OSS** | ✅ 采用 | 简历文件存储；海量存储；CDN加速；SDK完善 |

## 2. 核心表结构

### 2.1 用户表 (users)

```sql
CREATE TABLE users (
    id              BIGSERIAL PRIMARY KEY,
    phone           VARCHAR(20) UNIQUE COMMENT '手机号',
    password_hash   VARCHAR(255) COMMENT '密码hash',
    nickname        VARCHAR(50) COMMENT '昵称',
    avatar_url      VARCHAR(500) COMMENT '头像URL',
    member_level    TINYINT DEFAULT 0 COMMENT '会员等级:0免费,1Pro,2尊享',
    member_expire   DATETIME COMMENT '会员到期时间',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at      DATETIME COMMENT '软删除时间',
    INDEX idx_phone (phone),
    INDEX idx_created (created_at)
);
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键自增 |
| phone | VARCHAR(20) UNIQUE | 手机号，唯一 |
| password_hash | VARCHAR(255) | 密码哈希 |
| nickname | VARCHAR(50) | 昵称 |
| avatar_url | VARCHAR(500) | 头像URL |
| member_level | TINYINT | 会员等级：0免费，1Pro，2尊享 |
| member_expire | DATETIME | 会员到期时间 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |
| deleted_at | DATETIME | 软删除时间 |

### 2.2 简历表 (resumes)

```sql
CREATE TABLE resumes (
    id              BIGSERIAL PRIMARY KEY,
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    title           VARCHAR(100) COMMENT '简历标题',
    is_default      TINYINT DEFAULT 0 COMMENT '是否默认简历',
    file_url        VARCHAR(500) COMMENT '简历文件URL(PDF/Word)',
    parse_status    TINYINT DEFAULT 0 COMMENT '解析状态:0未解析,1解析中,2已解析',
    parse_result    JSON COMMENT 'AI解析结果',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at      DATETIME COMMENT '软删除时间',
    INDEX idx_user (user_id),
    FOREIGN KEY (user_id) REFERENCES users(id)
) );
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键自增 |
| user_id | BIGINT | 用户ID，外键 |
| title | VARCHAR(100) | 简历标题 |
| is_default | TINYINT | 是否默认简历 |
| file_url | VARCHAR(500) | 简历文件URL |
| parse_status | TINYINT | 解析状态：0未解析，1解析中，2已解析 |
| parse_result | JSON | AI解析结果 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |
| deleted_at | DATETIME | 软删除时间 |

### 2.3 简历详情表 (resume_details)

CREATE TABLE resume_details (

### 2.4 面试记录表 (interviews)

```sql
CREATE TABLE interviews (
    id              BIGSERIAL PRIMARY KEY,
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    resume_id       BIGINT COMMENT '使用的简历ID',
    job_position    VARCHAR(50) COMMENT '目标岗位',
    interview_style VARCHAR(20) COMMENT '面试风格:technical,pressure',
    interaction_mode VARCHAR(20) COMMENT '交互模式:text,voice,video',
    status          VARCHAR(20) DEFAULT 'pending' COMMENT '状态:pending,running,completed,cancelled',
    start_time      DATETIME COMMENT '开始时间',
    end_time        DATETIME COMMENT '结束时间',
    duration        INT COMMENT '面试时长(秒)',
    total_score     DECIMAL(5,2) COMMENT '综合评分',
    score_details   JSON COMMENT '多维度评分详情',
    summary         TEXT COMMENT '面试总结',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user (user_id),
    INDEX idx_status (status),
    INDEX idx_created (created_at),
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (resume_id) REFERENCES resumes(id)
) );
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键自增 |
| user_id | BIGINT | 用户ID，外键 |
| resume_id | BIGINT | 简历ID，外键 |
| job_position | VARCHAR(50) | 目标岗位 |
| interview_style | VARCHAR(20) | 面试风格：technical、pressure |
| interaction_mode | VARCHAR(20) | 交互模式：text、voice、video |
| status | VARCHAR(20) | 状态：pending、running、completed、cancelled |
| start_time | DATETIME | 开始时间 |
| end_time | DATETIME | 结束时间 |
| duration | INT | 面试时长（秒） |
| total_score | DECIMAL(5,2) | 综合评分 |
| score_details | JSON | 多维度评分详情 |
| summary | TEXT | 面试总结 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### 2.5 面试问答表 (interview_qas)

CREATE TABLE interview_qas (

### 2.6 题库表 (questions)

```sql
CREATE TABLE questions (
    id              BIGSERIAL PRIMARY KEY,
    job_position    VARCHAR(50) COMMENT '岗位:frontend,backend,fullstack',
    category        VARCHAR(30) COMMENT '类别:html,css,js,react,vue,java,python,go,db...',
    difficulty      TINYINT COMMENT '难度:1简单,2中等,3困难',
    content         TEXT COMMENT '问题内容',
    keywords        JSON COMMENT '考察关键词',
    standard_answer TEXT COMMENT '标准答案要点',
    follow_questions TEXT COMMENT '可能的追问问题',
    usage_count     INT DEFAULT 0 COMMENT '使用次数',
    correct_rate    DECIMAL(5,2) COMMENT '正确率',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_position (job_position),
    INDEX idx_category (category),
    INDEX idx_difficulty (difficulty)
) );
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键自增 |
| job_position | VARCHAR(50) | 岗位：frontend、backend、fullstack |
| category | VARCHAR(30) | 类别 |
| difficulty | TINYINT | 难度：1简单，2中等，3困难 |
| content | TEXT | 问题内容 |
| keywords | JSON | 考察关键词 |

| follow_questions | TEXT | 可能的追问问题 |
| usage_count | INT | 使用次数 |
| correct_rate | DECIMAL(5,2) | 正确率 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### 2.7 会员订单表 (member_orders)

CREATE TABLE member_orders (

### 2.8 用户收藏/错题表 (user_collections)

```sql
CREATE TABLE user_collections (
    id              BIGSERIAL PRIMARY KEY,
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    question_id     BIGINT COMMENT '收藏的题目ID',
    type            VARCHAR(20) COMMENT '类型:collect,wrong',
    interview_id    BIGINT COMMENT '关联的面试记录ID',
    note            TEXT COMMENT '用户笔记',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user_question (user_id, question_id),
    INDEX idx_type (type),
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (question_id) REFERENCES questions(id),
    FOREIGN KEY (interview_id) REFERENCES interviews(id)
) );
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键自增 |
| user_id | BIGINT | 用户ID，外键 |
| question_id | BIGINT | 题目ID，外键 |
| type | VARCHAR(20) | 类型：collect、wrong |
| interview_id | BIGINT | 面试ID，外键 |
| note | TEXT | 用户笔记 |
| created_at | DATETIME | 创建时间 |

## 5. 数据库命名规范

### 5.1 表命名规范

| 规范 | 说明 | 示例 |
|------|------|------|
| 命名法 | 单词小写，下划线分隔 | user_orders |
| 表名前缀 | 无特殊前缀 | users |
| 复数命名 | 使用复数形式 | users, questions |
| 主键命名 | id | id |
| 外键命名 | {表名}_id | user_id |

### 5.2 字段命名规范

| 规范 | 说明 | 示例 |
|------|------|------|
| 命名法 | 单词小写，下划线分隔 | created_at |
| 时间字段 | _at 后缀 | created_at, updated_at |
| 状态字段 | status | status |
| 布尔字段 | is_/has_ 前缀 | is_default |
| 软删除 | deleted_at | deleted_at |
| JSON字段 | 无特殊后缀 | parse_result |
