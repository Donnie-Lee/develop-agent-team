## 2. 发现的问题与偏差

### 2.1 第三方登录未覆盖

**问题**：PRD中提到"第三方登录(微信/Google)"，但技术方案中仅实现了手机号+验证码登录。

**建议方案**：
1. MVP阶段先只做手机号登录
2. 第三方登录作为后续迭代功能

**决策**：✅ 接受，确认MVP仅支持手机号登录

### 2.2 视频面试未实现

**问题**：PRD提到"视频模拟面试"，但接口设计中 interaction_mode 包含 video 类型，但实际未实现。

**建议方案**：
1. MVP阶段先实现文字+语音面试
2. 视频面试作为后续迭代功能

**决策**：✅ 接受，确认MVP仅支持文字+语音

### 2.3 数据库表引擎问题

**问题**：数据库设计文档中使用 `ENGINE=InnoDB`，但选型是 PostgreSQL。

**建议方案**：
- PostgreSQL 使用默认引擎，无需指定 ENGINE
- 需要修改建表语句

**修复**：❌ 需要修改数据库设计文档

### 2.4 服务间通信协议不一致

**问题**：技术架构中提到 gRPC 和 RabbitMQ，但接口文档中使用 REST API。

**建议方案**：
- 内部服务间通信使用 REST API（MVP简化）
- gRPC 作为后续性能优化选项

**决策**：✅ 接受，确认MVP使用REST API
