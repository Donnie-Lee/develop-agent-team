## 3. 依赖关系

### 3.1 技术依赖

| 依赖 | 类型 | 说明 |
|------|------|------|
| UI设计稿 | 前置 | 前端开发依赖UI交付 |
| 接口文档 | 前置 | 前后端并行依赖接口约定 |
| AI服务开通 | 外部 | 阿里云ASR/TTS/Qwen开通 |
| 支付申请 | 外部 | 支付宝/微信支付申请 |
| AI网关设计 | 前置 | Sprint 2后端任务前置 |

### 3.2 服务间依赖

```
用户服务
    ↓
简历服务 → 依赖用户服务
    ↓
面试服务 → 依赖简历服务 + AI网关 + 题库服务
    ↓
会员服务 → 依赖用户服务
    ↓
通知服务 → 依赖用户服务
```
