## 1. 页面概述

包含三个页面：
1. 面试配置页（岗位选择、风格选择）
2. 文字面试页（AI对话界面）
3. 面试报告页（面试结果展示）

## 5. 动效设计

### 5.1 消息出现

| 元素 | 动效 |
|------|------|
| AI消息 | 从左侧滑入 + 淡入，300ms |
| 用户消息 | 从右侧滑入 + 淡入，300ms |
| typing状态 | 三个点跳动动画 |

### 5.2 页面转场

| 转场 | 动效 |
|------|------|
| 配置→面试 | 页面向上滑出 |
| 面试→报告 | 页面淡入 |
