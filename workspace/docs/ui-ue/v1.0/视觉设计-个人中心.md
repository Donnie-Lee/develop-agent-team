## 2. 设计规格

### 2.1 用户信息卡片

| 元素 | 规格 |
|------|------|
| 背景 | 渐变 #1A73E8 → #4285F4 |
| 高度 | 160px |
| 内边距 | 20px |
| 头像 | 64x64px，圆形，白色边框 |
| 昵称 | 18px，白色，粗体 |
| 手机号 | 14px，白色半透明（opacity 0.8） |
| VIP徽章 | 右侧，金色标签 "VIP" |

### 2.2 会员权益提示条

| 元素 | 规格 |
|------|------|
| 背景 | #FFF8E1（浅黄） |
| 高度 | 48px |
| 文字 | "升级Pro会员，解锁无限面试" #5F6368 |
| 箭头 | #FB8C00 |
| 点击 | 跳转会员中心 |

### 2.3 面试统计卡片

| 元素 | 规格 |
|------|------|
| 布局 | 三列均分 |
| 背景 | #FFFFFF |
| 圆角 | 12px |
| 阴影 | 0 2px 8px rgba(0,0,0,0.08) |
| 内边距 | 16px |
| 数字 | 24px，粗体，#202124 |
| 标签 | 12px，#9AA0A6 |

### 2.4 功能入口列表

**列表项规格**：
| 元素 | 规格 |
|------|------|
| 高度 | 56px |
| 背景 | #FFFFFF |
| 左侧图标 | 24x24px，#5F6368 |
| 文字 | 16px，#202124 |
| 右侧箭头 | 20x20px，#9AA0A6 |
| 分隔线 | 1px solid #E8EAED |

**功能项**：
| 图标 | 文字 |
|------|------|

## 3. 交互状态

### 3.1 功能项点击

| 状态 | 效果 |
|------|------|
| 默认 | 白色背景 |
| 按下 | 背景#F8F9FA |
| 跳转 | 右箭头旋转或缩放动画 |

### 3.2 非会员提示

- 会员中心入口显示红色圆点提示 "开通"
- 面试次数显示 "3/3次"（非VIP限制）
