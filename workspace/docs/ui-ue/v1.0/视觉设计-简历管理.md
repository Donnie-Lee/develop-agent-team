## 3. 交互状态

### 3.1 简历操作

| 操作 | 反馈 |
|------|------|
| 设为默认 | Toast提示 "已设为默认简历" |
| 删除 | 确认弹窗 "确定删除该简历？" |
| 编辑 | 跳转编辑页 |
| 上传成功 | 显示文件名 + 解析状态 |

### 3.2 AI解析状态

| 状态 | 显示 |
|------|------|
| 未解析 | 灰色 "待解析" |
| 解析中 | 蓝色loading + "解析中..." |
| 解析成功 | 绿色勾 + "已解析" |
| 解析失败 | 红色叹号 + "解析失败，点击重试" |
