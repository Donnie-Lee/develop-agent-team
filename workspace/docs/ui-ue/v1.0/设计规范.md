---

## 1. 设计理念

### 1.1 产品定位

**InterviewAI（智能面试练兵场）** - 面向求职者的AI模拟面试平台

### 1.2 设计关键词

| 关键词 | 说明 |
|--------|------|
| 专业 | 体现面试服务的专业性 |
| 信任 | 建立用户对AI面试效果的信任 |
| 温暖 | 缓解面试焦虑，给予鼓励 |
| 高效 | 简洁操作，快速进入练习 |

### 1.3 设计风格

**风格定位**：现代专业、温暖友好

- 配色：蓝色为主（专业信任）+ 橙色点缀（温暖活力）
- 圆角：中等圆角（8px-12px），友好但不幼稚
- 阴影：轻阴影，增加层次感
- 插图：简约线条插画，传达积极向上

## 5. 组件规范

### 5.1 按钮

**主要按钮**：
- 背景：#1A73E8
- 文字：#FFFFFF
- 圆角：8px
- 高度：44px（移动端）、40px（桌面端）
- hover：#1557B0

**次要按钮**：
- 背景：#FFFFFF
- 边框：1px solid #E8EAED
- 文字：#202124
- hover：背景#F8F9FA

**文字按钮**：
- 文字：#1A73E8
- hover：下划线

### 5.2 输入框

- 高度：44px
- 边框：1px solid #E8EAED
- 圆角：8px
- 聚焦边框：2px solid #1A73E8
- placeholder颜色：#9AA0A6

### 5.3 卡片

- 背景：#FFFFFF
- 圆角：12px
- 阴影：0 1px 3px rgba(0,0,0,0.12)
- hover阴影：0 4px 12px rgba(0,0,0,0.15)
- 内边距：16px

### 5.4 头像

- 大头像：80px
- 中头像：48px
- 小头像：32px
- 圆角：50%（圆形）

## 7. 动效规范

### 7.1 过渡动画

| 场景 | 时长 | 缓动 |
|------|------|------|
| 按钮hover | 150ms | ease-out |
| 页面切换 | 300ms | ease-in-out |
| 弹窗出现 | 250ms | ease-out |
| 加载 | 1000ms | linear（循环） |

### 7.2 反馈动效

| 反馈 | 动效 |
|------|------|
| 点击 | scale(0.98) |
| 成功 | 绿色对勾 + 轻微弹跳 |
| 错误 | 轻微抖动 |
