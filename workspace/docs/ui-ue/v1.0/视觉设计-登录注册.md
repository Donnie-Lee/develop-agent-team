## 3. 交互状态

### 3.1 表单验证

| 场景 | 状态 |
|------|------|
| 手机号为空 | 输入框边框正常，提示"请输入手机号" |
| 手机号格式错误 | 输入框边框变红#EA4335，提示"手机号格式不正确" |
| 验证码为空 | 输入框边框变红#EA4335，提示"请输入验证码" |
| 验证码错误 | 整体提示"验证码错误，请重新输入" |
| 倒计时中 | 按钮显示倒计时 "59s"，不可点击 |

### 3.2 登录流程

| 步骤 | 状态 |
|------|------|
| 1. 点击登录 | 按钮显示loading "登录中..." |
| 2. 验证通过 | 跳转到首页 |
| 3. 验证失败 | 显示错误提示 |

---

## 4. 页面流程

### 4.1 登录流程

```
欢迎页 → 输入手机号 → 获取验证码 → 输入验证码 → 登录成功 → 首页
                              ↓
                        第三方登录 → 授权 → 登录成功 → 首页
```

### 4.2 注册流程

（新用户手机号登录即自动注册）
```
输入手机号 → 获取验证码 → 输入验证码 → 登录成功 → 首页
                                        ↓
                                   引导完善个人信息
```
