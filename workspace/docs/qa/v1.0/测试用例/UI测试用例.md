## 1. 测试概述

### 1.1 测试范围

本次UI测试覆盖Sprint 1 "用户与简历"阶段的Portal端（H5）页面：

| 页面 | 文件路径 | 功能 |
|------|----------|------|
| 登录注册页 | `/workspace/frontend/h5/src/views/Login.vue` | 手机号登录、验证码注册 |
| 个人中心页 | `/workspace/frontend/h5/src/views/Profile.vue` | 个人信息展示、菜单导航 |
| 简历列表页 | `/workspace/frontend/h5/src/views/ResumeList.vue` | 简历列表、创建、上传 |
| 简历编辑页 | `/workspace/frontend/h5/src/views/ResumeEdit.vue` | 简历详情编辑 |

### 1.2 测试环境

| 环境项 | 地址 |
|--------|------|
| H5前端 | http://localhost:3001 |
| 后端代理 | http://localhost:3001/api |

### 1.3 测试标准

| 优先级 | 说明 |
|--------|------|
| P0 | 核心功能，必须通过 |
| P1 | 重要功能，应通过 |
| P2 | 一般功能，尽量通过 |
| P3 | 建议改进，不阻塞发布 |
