## 1. 测试概述

### 1.1 测试范围

本次接口测试覆盖Sprint 1 "用户与简历"阶段的所有后端API接口：

#### 用户服务接口 (user-service)

| 接口路径 | 方法 | 功能 | 优先级 |
|----------|------|------|--------|
| /api/v1/user/send-code | POST | 发送验证码 | P0 |
| /api/v1/user/login-phone | POST | 手机号登录 | P0 |
| /api/v1/user/logout | POST | 退出登录 | P0 |
| /api/v1/user/refresh-token | POST | 刷新Token | P0 |
| /api/v1/user/info | GET | 获取用户信息 | P0 |
| /api/v1/user/info | PUT | 更新用户信息 | P0 |
| /api/v1/user/password | PUT | 修改密码 | P1 |

#### 简历服务接口 (resume-service)

| 接口路径 | 方法 | 功能 | 优先级 |
|----------|------|------|--------|
| /api/v1/resumes | GET | 获取简历列表 | P0 |
| /api/v1/resumes | POST | 创建简历 | P0 |
| /api/v1/resumes/{id} | GET | 获取简历详情 | P0 |
| /api/v1/resumes/{id} | PUT | 更新简历 | P0 |
| /api/v1/resumes/{id} | DELETE | 删除简历 | P0 |
| /api/v1/resumes/upload | POST | 上传简历文件 | P0 |
| /api/v1/resumes/{id}/parse | POST | 解析简历 | P0 |
| /api/v1/resumes/{id}/analyze | GET | 获取分析报告 | P1 |
| /api/v1/resumes/{id}/suggestions | GET | 获取优化建议 | P1 |

### 1.2 接口规范

#### 统一响应结构

```json
{
    "code": 0,
    "message": "success",
    "data": { },
    "timestamp": 1699999999999,
    "traceId": "xxx"
}
```

#### 错误码说明

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 1001 | 参数错误 |
| 1002 | 缺少必填参数 |
| 1003 | 参数格式错误 |
| 2001 | Token无效 |
| 2002 | Token过期 |
| 3001 | 资源不存在 |
| 3002 | 资源已存在 |
