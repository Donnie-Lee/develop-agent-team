## 1. 测试概述

### 1.1 测试背景
AI面试练习平台（InterviewAI）是一个面向求职者的AI模拟面试平台，本测试针对Sprint 1交付的用户模块和简历模块进行功能测试。

### 1.2 测试范围
- 用户模块：发送验证码、手机号登录、获取用户信息、退出登录
- 简历模块：创建简历、获取简历列表、获取简历详情、更新简历、删除简历

### 1.3 测试环境
| 环境项 | 说明 |
|--------|------|
| user-service | http://localhost:8081 |
| resume-service | http://localhost:8082 |
| admin前端代理 | http://localhost:3000 |
| h5前端代理 | http://localhost:3001 |

---

## 2. 用户模块测试用例

### 2.1 发送验证码

| 用例编号 | UM-001 |
|----------|--------|
| 用例名称 | 发送验证码 |
| 接口路径 | POST /api/v1/user/send-code |
| 请求方法 | POST |
| 请求头 | Content-Type: application/json |

**请求参数：**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| phone | string | 是 | 手机号 |
| type | string | 是 | 类型: login/register |

**测试步骤：**
1. 构造正确的请求参数（手机号13800138000，type=login）
2. 发送POST请求到 http://localhost:8081/api/v1/user/send-code
3. 记录响应结果

**预期结果：**
- 响应码：200
- 响应体包含 code: 0, message: "success"
- data.expiresIn 应为 300（5分钟）

---
