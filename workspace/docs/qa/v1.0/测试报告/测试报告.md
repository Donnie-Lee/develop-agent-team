## 4. 缺陷详情

### 4.1 resume_details表缺少deleted_at列（BUG-005）

| 项目 | 内容 |
|------|------|
| Bug ID | BUG-005 |
| 严重程度 | P1（严重） |
| 发现时间 | 2026-04-07 |
| 发现阶段 | 功能测试 |
| 发现人员 | qa-tester |
| 问题描述 | 获取简历详情、更新简历、删除简历接口返回500错误 |
| 根本原因 | resume_details表缺少deleted_at列，但代码中使用逻辑删除（WHERE deleted_at IS NULL） |
| 影响范围 | GET /api/v1/resumes/{id}, PUT /api/v1/resumes/{id}, DELETE /api/v1/resumes/{id} |
| 错误信息 | org.postgresql.util.PSQLException: ERROR: column "deleted_at" does not exist |
| 修复措施 | 在resume_details表添加deleted_at列，或修改代码使用物理删除 |
| 修复状态 | **已修复** |
| 验证结果 | 2026-04-07：已在数据库中添加deleted_at列，简历详情、更新、删除接口测试通过 |

|------|------|

### 4.3 简历软删除失效（BUG-007）

| 项目 | 内容 |
|------|------|
| Bug ID | BUG-007 |
| 严重程度 | P1（严重） |
| 发现时间 | 2026-04-08 |
| 发现阶段 | 复核测试 |
| 发现人员 | qa-tester |
| 问题描述 | 简历删除接口返回成功，但deleted_at字段未更新，已删除简历仍可被查询访问 |
| 根本原因 | ResumeService.deleteResume方法使用updateById而非deleteById，MyBatis-Plus的@TableLogic注解在updateById时不生效 |
| 影响范围 | DELETE /api/v1/resumes/{id} |
| 错误现象 | 删除后数据库deleted_at仍为null，删除的简历仍在列表中出现 |
| 修复措施 | 修改ResumeService.deleteResume方法，调用resumeRepository.deleteById(resumeId)而非手动更新deletedAt |
| 修复状态 | **待修复** |

## 7. 修复建议

### 7.1 BUG-007 修复方案

**修改ResumeService.deleteResume方法**

当前代码：
```java
// 软删除
resume.setDeletedAt(LocalDateTime.now());
resumeRepository.updateById(resume);
```

修改为：
```java
// 软删除 - 使用deleteById让@TableLogic注解生效
resumeRepository.deleteById(resumeId);
```

**原因**：MyBatis-Plus的`@TableLogic`注解只在调用`deleteById/deleteBatchIds`等删除方法时才会自动添加逻辑删除的更新操作。直接使用`updateById`不会触发逻辑删除。
