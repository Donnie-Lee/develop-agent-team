## 1. 产品概述

### 1.1 产品名称

**产品名称**：InterviewAI（智能面试练兵场）

### 1.2 产品定位

一款面向求职者的AI模拟面试平台，通过人工智能技术为用户提供沉浸式、个性化、专业化的面试练习体验，帮助用户提升面试技能、增强求职竞争力。

### 1.3 产品slogan

> "让每一次练习，都离offer更近一步"

### 1.4 核心价值主张

| 价值点 | 说明 |
|--------|------|
| **随时随地** | 7x24小时可用，利用碎片时间高效练习 |
| **真实模拟** | AI还原真实面试场景，涵盖多种面试风格 |
| **个性化定制** | 根据用户简历和目标岗位生成针对性面试题 |
| **即时反馈** | 面试结束后立即获得详细反馈与改进建议 |
| **隐私安全** | 练习过程仅用户可见，无需担心信息泄露 |

### 3.4 面试模块

#### 3.4.1 面试配置

**岗位选择**：

| 岗位类别 | 具体方向 |
|----------|----------|
| 前端开发 | React/Vue、小程序、移动端 |
| 后端开发 | Java/Python/Go、微服务、数据库 |
| 全栈开发 | 前端+后端综合能力 |

**面试风格**：

| 风格 | 描述 | 特点 |
|------|------|------|
| 技术面试 | 考察专业知识与实战能力 | 问题深入、手撕算法、系统设计 |
| 压力面试 | 模拟高压面试场景 | 连续追问、否定质疑、时间压力 |

**交互形式**：

| 形式 | 说明 | 适用场景 |
|------|------|----------|
| 文字对话 | 类似ChatGPT的文字交互 | 快速练习、异步练习 |
| 语音对话 | 语音识别+合成 | 口语表达练习 |
| 视频模拟 | 摄像头+语音 | 真实场景还原、心理适应 |

##### 3.4.2 面试时长控制

| 控制方式 | 说明 |
|----------|------|
| **自适应时长** | AI根据面试深度自主判断，深度对话可延长，简单问题快速过 |
| 单次面试建议时长 | 10-30分钟（根据问题深度动态调整） |
| AI节奏控制 | AI判断是否需要追问，决定进入下一问题或继续深挖 |

#### 3.4.3 AI模拟面试流程

```
┌─────────────────────────────────────────────────────────────┐
│                      面试流程                                 │
├─────────────────────────────────────────────────────────────┤
│  1. 选择目标岗位  →  2. 选择面试风格  →  3. 选择交互形式     │
│         ↓                  ↓                  ↓              │
│  4. 上传/选择简历   →   5. AI生成面试题   →   6. 开始面试    │
│         ↓                  ↓                  ↓              │
│  7. AI提问         →   8. 用户回答        →   9. 继续追问    │
│         ↓                  ↓                  ↓              │
│  10. 自适应结束    →   11. 生成报告       →   12. 查看反馈   │
└─────────────────────────────────────────────────────────────┘
```

**面试节奏说明**：
- AI根据用户回答质量决定是否追问（最多追问2-3轮）
- 回答充分则进入下一问题，回答浅显则继续深挖
- 整体时长根据面试深度自适应调整（10-30分钟）

#### 3.4.4 面试过程说明

**文字对话模式**：

| 阶段 | AI行为 | 用户行为 |
|------|--------|----------|
| 开场 | 自我介绍，说明面试岗位和时长 | - |
| 提问 | 提出面试问题 | 输入回答 |
| 追问 | 根据回答深度追问（最多2-3轮） | 输入回答 |
| 过渡 | "接下来进入下一个问题" | - |
| 结尾 | "面试到此结束，感谢参与" | - |

**语音模式**：

| 阶段 | AI行为 | 用户行为 |
|------|--------|----------|
| 开场 | 语音自我介绍+问题 | 语音回答 |
| 提问 | 语音提问 | 语音回答 |
| 追问 | 语音追问 | 语音回答 |
| 结尾 | 语音结束语 | - |

**追问规则**：
- 每个问题最多追问2-3轮
- AI根据关键词、技术深度判断是否继续追问
- 用户也可以主动说"我准备好了"进入下一题
