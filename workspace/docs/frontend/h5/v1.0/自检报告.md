## 4. 接口对接情况

### 4.1 API代理配置

**文件**：`vite.config.js`

```javascript
server: {
  port: 3001,
  proxy: {
    '/api/v1/user': {
      target: 'http://localhost:8082',
      changeOrigin: true
    },
    '/api/v1/resumes': {
      target: 'http://localhost:8081',
      changeOrigin: true
    }
  }
}
```

**说明**：已修复端口配置错误（user-service:8082, resume-service:8081）

### 4.2 后端服务端口对应

| 服务 | 端口 | 前端代理路径 |
|------|------|-------------|
| user-service | 8082 | /api/v1/user |
| resume-service | 8081 | /api/v1/resumes |

**注意**：代理端口已修正，原配置中 user 和 resumes 的端口配置是反的。

### 4.3 API模块封装

**文件**：`src/api/index.js`

- 统一封装 Axios 实例
- 请求拦截器：自动注入 Bearer Token
- 响应拦截器：统一处理 401 过期、错误提示

### 4.4 Pinia Stores

**用户Store** (`src/stores/user.js`)：
- `sendCode(phone)` - 发送验证码
- `loginWithCode(phone, code)` - 手机号登录
- `logout()` - 退出登录
- `fetchUserInfo()` - 获取用户信息
- `updateUserInfo(data)` - 更新用户信息

**简历Store** (`src/stores/resume.js`)：
- `fetchResumes()` - 获取简历列表
- `fetchResumeDetail(id)` - 获取简历详情
- `createResume(data)` - 创建简历
- `updateResume(id, data)` - 更新简历
- `deleteResume(id)` - 删除简历
- `uploadFile(file)` - 上传简历文件
- `parseResume(id)` - 解析简历
- `setDefaultResume(id)` - 设置默认简历
