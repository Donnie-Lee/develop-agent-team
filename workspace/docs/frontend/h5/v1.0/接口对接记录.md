### 8.3 接口路径不匹配问题

#### 8.3.1 fetchQuestions 问题

**前端调用**:
```javascript
// interview.js
export const fetchQuestions = (interviewId) => {
  return api.get(`/interview/${interviewId}/questions`)
}
```
**实际后端路径**: 无此接口！

**后端实际接口**:
- `POST /api/v1/interview/{id}/start` - 开始面试会话
- `GET /api/v1/interview/session/{sessionId}/questions` - 获取会话问题

**问题**: 前端直接调用 `/interview/{id}/questions`，但后端需要先调用 `/start` 获取 sessionId，再通过 session 获取问题。

#### 8.3.2 submitAnswer 问题

**前端调用**:
```javascript
// interview.js
export const submitAnswer = (interviewId, answerData) => {
  return api.post(`/interview/${interviewId}/answer`, answerData)
}
```

**后端实际路径**:
```java
// InterviewController.java
@PostMapping("/answer")
public Result<QuestionResponse> submitAnswer(
    @RequestHeader("Authorization") String authHeader,
    @Valid @RequestBody SubmitAnswerRequest request) {
    // 注意：路径参数 interviewId 在 request 中，不是路径参数
}
```

**问题**: 前端将 interviewId 放在路径参数，后端期望在 request body 中。

### 8.5 建议修改方案

#### 8.5.1 前端修改 (interview.js)

```javascript
// fetchQuestions 需要先 start 再获取问题
export const fetchQuestions = async (interviewId) => {
  // 1. 先开始面试会话
  const startRes = await api.post(`/interview/${interviewId}/start`)
  const sessionId = startRes.data.data.sessionId
  // 2. 再获取问题
  return api.get(`/interview/session/${sessionId}/questions`)
}

// submitAnswer 参数调整
export const submitAnswer = (answerData) => {
  // interviewId 放到 body 中
  return api.post('/interview/answer', answerData)
}
```
