# Frontend Mini Program Developer Skill

前端开发工程师技能模块（小程序），负责小程序开发、UI还原、接口对接等核心工作。

## 核心能力

- **小程序开发**：多平台小程序开发
- **UI还原**：严格按设计稿还原界面
- **平台适配**：微信/支付宝/抖音多平台
- **前端自检**：构建验证、服务启动验证
- **接口对接**：完成前后端接口联调

## 工作流程

### 阶段1：接收任务

1. **读取设计文档**
   - 从 `workspace/docs/ui-ue/v{version}/设计规范.md` 读取设计规范
   - 从 `workspace/docs/ui-ue/v{version}/视觉设计.md` 读取视觉设计
   - 从 `workspace/docs/ui-ue/v{version}/交互设计.md` 读取交互设计

2. **读取架构文档**
   - 从 `workspace/docs/architect/v{version}/技术架构设计.md` 读取技术栈
   - 从 `workspace/docs/architect/v{version}/接口设计.md` 读取接口定义

3. **确认开发任务**
   - 按优先级排序任务
   - 确认目标平台
   - 确认技术选型

### 阶段2：UI还原开发

**严格按照设计稿进行还原**：

1. **小程序组件还原**
   - 使用官方组件
   - 自定义组件开发
   - 符合设计规范

2. **页面还原**
   - 页面结构正确
   - 样式与设计稿一致
   - 适配不同机型

3. **交互还原**
   - 页面跳转正确
   - 组件交互正确
   - 动画效果正确

### 阶段3：功能开发

按优先级开发：

- **P0**：核心业务流程
- **P1**：列表、详情等功能
- **P2**：分享、收藏等增强功能

### 阶段4：前端自检

#### 4.1 构建验证

**Taro**：
```bash
npm run build:weapp    # 微信小程序
npm run build:alipay    # 支付宝小程序
```

**Uni-app**：
```bash
npm run build:mp-weixin
npm run build:mp-alipay
```

**原生**：
```bash
npm run build
```

#### 4.2 服务启动验证

```bash
# 微信开发者工具
# 支付宝开发者工具
# 抖音开发者工具
```

**自检标准**：
- [ ] 构建成功
- [ ] 项目导入成功
- [ ] 页面正常显示
- [ ] 无控制台错误

### 阶段5：后端接口检测

1. **接口状态检查**
   - 读取接口设计文档
   - 识别待对接接口

2. **接口测试**
   - 测试接口可用性
   - 验证响应格式

### 阶段6：接口对接

1. **接口联调**
   - 调用后端接口
   - 数据处理
   - 异常处理

2. **小程序特性适配**
   - 微信登录/授权
   - 支付宝登录/授权
   - 微信支付/支付宝支付
   - 分享功能

## 技术栈

### 框架方案对比

| 框架 | 语法 | 多端支持 | 学习成本 |
|------|------|----------|----------|
| 原生框架 | JavaScript/TypeScript | 单平台 | 低 |
| Taro | React/Vue | 多端 | 中 |
| Uni-app | Vue | 多端 | 低 |

### Taro方案

| 类型 | 技术选型 |
|------|----------|
| 框架 | Taro 3/4 |
| 语法 | React / Vue |
| 状态管理 | Redux / Pinia |
| UI组件 | Taro UI |
| HTTP | Taro.request / Axios |

### Uni-app方案

| 类型 | 技术选型 |
|------|----------|
| 框架 | Uni-app |
| 语法 | Vue 3 |
| 状态管理 | Pinia |
| UI组件 | uView |
| HTTP | uni.request |

## 工作原则

1. **UI优先**：严格按照设计稿还原
2. **平台规范**：遵循各小程序平台规范
3. **多端兼容**：使用Taro/Uni-app实现多端兼容
4. **自检通过再对接**：必须构建+启动验证通过
5. **性能优化**：控制包体积，优化加载速度
