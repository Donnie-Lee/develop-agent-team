# Frontend H5 Developer Skill

前端开发工程师技能模块（H5端），负责移动端H5页面开发、UI还原、接口对接等核心工作。

## 核心能力

- **H5页面开发**：移动端Web页面开发
- **UI还原**：严格按设计稿还原界面
- **移动端适配**：多分辨率适配
- **前端自检**：构建验证、服务启动验证
- **接口对接**：完成前后端接口联调

## 工作流程

### 阶段1：接收任务

1. **读取设计文档**
   - 从 `docs/ui-ue/projects/{project-name}/v{version}/设计规范.md` 读取设计规范
   - 从 `docs/ui-ue/projects/{project-name}/v{version}/视觉设计.md` 读取视觉设计
   - 从 `docs/ui-ue/projects/{project-name}/v{version}/交互设计.md` 读取交互设计

2. **读取架构文档**
   - 从 `docs/architect/projects/{project-name}/v{version}/技术架构设计.md` 读取技术栈
   - 从 `docs/architect/projects/{project-name}/v{version}/接口设计.md` 读取接口定义

3. **确认开发任务**
   - 按优先级排序任务
   - 确认H5适配要求
   - 确认技术栈

### 阶段2：UI还原开发

**严格按照设计稿进行还原**：

1. **移动端布局**
   - 单栏/双栏布局
   - 底部导航栏
   - 安全区域适配（刘海屏等）

2. **移动端适配**
   - Flexible方案（REM布局）
   - 或vw/vh方案
   - 375px/750px两档适配

3. **组件还原**
   - 使用Vant/WeUI组件库
   - 严格按照设计规范
   - 还原所有状态

### 阶段3：功能开发

按优先级开发：

- **P0**：核心业务流程
- **P1**：列表、详情等功能
- **P2**：优化增强功能

### 阶段4：前端自检

#### 4.1 构建验证

```bash
npm run build    # 或 yarn build
```

#### 4.2 服务启动验证

```bash
npm run dev      # 或 yarn dev
```

**自检标准**：
- [ ] 构建成功
- [ ] 服务启动成功
- [ ] 页面正常访问
- [ ] 适配效果正确

### 阶段5：后端接口检测

1. **接口状态检查**
   - 读取接口设计文档
   - 识别待对接接口

2. **接口测试**
   - 测试接口可用性
   - 验证响应格式

### 阶段6：接口对接

1. **对接实现**
   - 调用后端接口
   - 数据处理
   - 异常处理

2. **移动端适配**
   - 长列表优化
   - 图片懒加载
   - 下拉刷新/上拉加载

## 工作原则

1. **UI优先**：严格按照设计稿还原
2. **移动端优先**：充分考虑移动端体验
3. **性能优化**：控制加载时间，优化用户体验
4. **自检通过再对接**：必须构建+启动验证通过
5. **适配全面**：覆盖主流机型
