## 1. 接口规范

### 1.1 RESTful规范

| 规范 | 说明 |
|------|------|
| URL规范 | `/api/v1/{module}/{resource}` |
| 动词规范 | GET (查询) / POST (创建) / PUT (更新) / DELETE (删除) |
| 认证方式 | Bearer Token (JWT) |
| 数据格式 | JSON |
| 字符编码 | UTF-8 |

### 1.2 通用响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "timestamp": 1709395200000
}
```

### 1.3 错误码定义

| 错误码 | 说明 | HTTP Status |
|--------|------|-------------|
| 0 | 成功 | 200 |
| 1001 | 参数错误 | 400 |
| 1002 | 未授权 | 401 |
| 1003 | 权限不足 | 403 |
| 1004 | 资源不存在 | 404 |
| 1005 | 业务规则冲突 | 409 |
| 2001 | 服务器内部错误 | 500 |
| 2002 | 服务不可用 | 503 |
| 3001 | 库存不足 | 400 |
| 3002 | 订单状态不允许 | 400 |
| 3003 | 支付失败 | 400 |
| 3004 | 退款失败 | 400 |

## 3. 接口详情

### 3.1 用户注册

**基本信息**：

| 字段 | 内容 |
|------|------|
| 请求路径 | /api/v1/user/register |
| 请求方法 | POST |
| 认证方式 | 无 |

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | string | 是 | 用户名，6-20位字母数字 |
| password | string | 是 | 密码，8-20位，包含大小写和数字 |
| email | string | 否 | 邮箱 |
| phone | string | 否 | 手机号 |

**请求示例**：

```json
{
  "username": "user001",
  "password": "Password123",
  "email": "user@example.com",
  "phone": "13800138000"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | int | 状态码 |
| message | string | 状态信息 |
| data | object | 返回数据 |
| data.userId | long | 用户ID |
| data.username | string | 用户名 |
| token | string | JWT Token |

**响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "userId": 10001,
    "username": "user001",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  },
  "timestamp": 1709395200000
}
```

### 3.3 创建订单

**基本信息**：

| 字段 | 内容 |
|------|------|
| 请求路径 | /api/v1/order |
| 请求方法 | POST |
| 认证方式 | Bearer Token |

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| addressId | long | 是 | 收货地址ID |
| paymentMethod | string | 是 | 支付方式: alipay/wechat/pay |
| cartItems | array | 是 | 购物车商品列表 |
| cartItems[].cartId | long | 是 | 购物车ID |
| cartItems[].quantity | int | 是 | 购买数量 |
| couponCode | string | 否 | 优惠券码 |
| remark | string | 否 | 订单备注 |

**请求示例**：

```json
{
  "addressId": 1001,
  "paymentMethod": "alipay",
  "cartItems": [
    {
      "cartId": 1,
      "quantity": 2
    }
  ],
  "couponCode": "DISCOUNT10",
  "remark": "请小心轻放"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | int | 状态码 |
| message | string | 状态信息 |
| data | object | 返回数据 |
| data.orderId | long | 订单ID |
| data.orderNo | string | 订单号 |
| data.totalAmount | decimal | 订单总额 |
| data.payAmount | decimal | 实付金额 |
| data.payUrl | string | 支付链接(跳转支付) |

**响应示例**：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "orderId": 10001,
    "orderNo": "ORD2026040200001",
    "totalAmount": 299.00,
    "payAmount": 269.00,
    "payUrl": "https://pay.example.com/?orderNo=ORD2026040200001"
  },
  "timestamp": 1709395200000
}
```

### 3.8 支付回调

**基本信息**：

| 字段 | 内容 |
|------|------|
| 请求路径 | /api/v1/pay/callback |
| 请求方法 | POST |
| 认证方式 | 签名验证 |

**请求参数**（根据支付渠道不同）：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| orderNo | string | 是 | 订单号 |
| payNo | string | 是 | 支付流水号 |
| status | string | 是 | 支付状态: SUCCESS/FAIL |
| amount | decimal | 是 | 支付金额 |
| sign | string | 是 | 签名 |
| timestamp | long | 是 | 时间戳 |

**处理流程**：

1. 验签：验证回调签名
2. 幂等检查：检查payNo是否已处理
3. 订单状态更新：更新订单状态为已支付
4. 库存扣减：触发库存扣减
5. 积分发放：触发积分发放（可选）
6. 返回成功：返回success

## 5. 安全规范

### 5.1 签名机制

**支付接口签名**：

1. 将请求参数按字典序排序
2. 拼接成 key1=value1&key2=value2 格式
3. 在末尾拼接密钥
4. 计算MD5/SHA256值作为签名

### 5.2 敏感数据处理

| 数据类型 | 处理方式 |
|----------|----------|
| 密码 | 传输加密，存储BCrypt |
| 手机号 | 脱敏显示 138****8000 |
| 身份证 | 脱敏显示 310***********1234 |
| 银行卡 | 脱敏显示 6222****1234 |
