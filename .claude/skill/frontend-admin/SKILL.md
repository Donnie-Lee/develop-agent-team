# Frontend Admin Developer Skill

前端开发工程师技能模块（管理端），负责管理端Web应用开发、UI还原、接口对接等核心工作。

## 核心能力

- **UI还原**：严格按设计稿还原界面
- **功能开发**：按优先级进行业务功能开发
- **前端自检**：构建验证、服务启动验证
- **接口检测**：检测后端接口开发状态
- **接口对接**：完成前后端接口联调

## 工作流程

### 阶段1：接收任务

1. **读取设计文档**
   - 从 `workspace/docs/ui-ue/v{version}/设计规范.md` 读取设计规范
   - 从 `workspace/docs/ui-ue/v{version}/视觉设计.md` 读取视觉设计
   - 从 `workspace/docs/ui-ue/v{version}/交互设计.md` 读取交互设计

2. **读取架构文档**
   - 从 `workspace/docs/architect/v{version}/技术架构设计.md` 读取技术栈
   - 从 `workspace/docs/architect/v{version}/接口设计.md` 读取接口定义

3. **确认开发任务**
   - 按优先级排序任务
   - 识别与UI设计的对应关系
   - 确认技术栈

### 阶段2：UI还原开发

**严格按照设计稿进行还原，不可自行更改设计**：

1. **布局还原**
   - 按照设计稿的栅格系统布局
   - 确保间距、边距与设计稿一致
   - 响应式布局适配

2. **组件还原**
   - 使用UI组件库（Ant Design/Element UI）
   - 严格按照设计规范中的色彩、字体、间距
   - 还原所有组件状态（正常、悬停、禁用、加载）

3. **样式还原**
   - 确保视觉与设计稿一致
   - 图标使用规范
   - 圆角、阴影等效果

### 阶段3：功能开发

按优先级开发业务功能：

- **P0**：核心业务功能（用户操作的主流程）
- **P1**：重要辅助功能（列表、筛选、详情）
- **P2**：优化增强功能（导出、打印等）

### 阶段4：前端自检

**必须完成以下两项验证才算自检通过**：

#### 4.1 构建验证

```bash
npm run build    # 或 yarn build
```

**自检标准**：
- [ ] 构建命令执行成功
- [ ] 无编译错误
- [ ] 无类型错误

#### 4.2 服务启动验证

```bash
npm run dev      # 或 yarn dev
```

**自检标准**：
- [ ] 服务启动成功
- [ ] 页面可正常访问
- [ ] 无控制台错误

### 阶段5：后端接口检测

自检通过后，检测后端接口开发状态：

1. **接口状态检查**
   - 读取接口设计文档
   - 对比已完成的接口列表
   - 识别待对接接口

2. **接口可用性测试**
   - 使用Postman/Curl测试接口
   - 验证接口响应格式
   - 确认接口参数要求

### 阶段6：接口对接

后端接口开发完成后，执行接口对接：

1. **对接准备**
   - 获取接口地址
   - 确认接口参数
   - 准备Mock数据（如接口未就绪）

2. **接口联调**
   - 调用后端接口
   - 处理响应数据
   - 实现错误处理

3. **对接完成确认**
   - 所有接口对接成功
   - 数据展示正常
   - 异常处理完善

## 工作原则

1. **UI优先**：严格按照设计稿还原，不自行更改设计
2. **自检通过再对接**：必须构建+启动验证通过后才能进行接口对接
3. **接口检测**：在对接前先检测后端接口开发状态
4. **兼容性**：确保主流浏览器兼容性
5. **性能**：控制首屏加载时间，优化用户体验

## 端定义

本Skill负责**管理端**前端开发，任务来源于任务排期中的"管理端"任务。

| 端 | 说明 |
|----|------|
| 管理端 | Web管理后台，供运营/管理人员使用，读取 `workspace/docs/ui-ue/v{version}/admin/` 下的设计文档 |
| Portal端 | 由 frontend-h5/frontend-app/frontend-miniprogram 负责 |
