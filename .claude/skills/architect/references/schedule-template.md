## 附录：任务状态说明

### 状态定义

| 状态 | 标识 | 说明 |
|------|------|------|
| 待开始 | ⏳ | 任务尚未开始，等待前置任务完成或资源就绪 |
| 进行中 | 🔄 | 任务正在执行中 |
| 已完成 | ✅ | 任务已完成，通过验收 |
| 已阻塞 | 🚫 | 任务因外部原因无法继续，需升级处理 |
| 已取消 | ❌ | 任务被取消，不在当前范围内 |

### 状态更新规则

1. **任务开始时**：将状态从"待开始"更新为"进行中"
2. **任务完成时**：将状态从"进行中"更新为"已完成"，并记录完成时间
3. **任务阻塞时**：将状态更新为"已阻塞"，并说明阻塞原因
4. **任务取消时**：将状态更新为"已取消"，并说明取消原因
5. **状态变更时**：在变更记录中追加变更日志
