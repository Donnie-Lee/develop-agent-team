# UI/UE Skill

UI/UE设计师技能模块，负责视觉设计、交互设计、多端设计规范输出等核心工作。

## 核心能力

- **视觉设计**：色彩体系、字体规范、图标设计、组件样式
- **交互设计**：页面流程、动效设计、异常处理
- **设计规范**：制定统一的设计系统，确保多端一致性
- **多端设计**：管理端、H5、移动端App、小程序四端分别设计

## 多端产出说明

本Skill为以下四个端分别产出设计文档：

| 端 | 适配平台 | 输出目录 |
|----|----------|----------|
| 管理端 | Web管理后台 | `workspace/docs/ui-ue/v{version}/admin/` |
| H5端 | 移动端H5网页 | `workspace/docs/ui-ue/v{version}/h5/` |
| 移动端App | iOS/Android App | `workspace/docs/ui-ue/v{version}/app/` |
| 小程序 | 微信/支付宝/抖音小程序 | `workspace/docs/ui-ue/v{version}/miniprogram/` |

## 工作流程

### 阶段1：接收输入

1. **读取PM文档**
   - 从 `workspace/docs/pm/v{version}/PRD.md` 读取产品需求
   - 从 `workspace/docs/pm/v{version}/原型说明.md` 读取原型设计

2. **读取架构文档**
   - 从 `workspace/docs/architect/v{version}/技术架构设计.md` 读取技术架构
   - 从 `workspace/docs/architect/v{version}/接口设计.md` 读取接口设计

3. **综合分析**
   - 理解产品定位和目标用户
   - 了解技术限制和适配要求
   - 确定设计方向和风格
   - 确认需要设计的端

### 阶段2：多端UI设计

**为每个端分别调用UI-UX-PRO-MAX进行设计**：

#### 2.1 管理端设计

1. **设计准备**
   - 确定管理端功能模块
   - 确定页面结构
   - 确定交互需求

2. **调用UI-UX-PRO-MAX**
   - 使用Skill工具调用 `ui-ux-pro-max`
   - 提供管理端设计上下文
   - 获取设计建议

3. **输出管理端设计文档**

#### 2.2 H5端设计

1. **设计准备**
   - 确定H5页面结构
   - 确定移动端适配方案
   - 确定交互需求

2. **调用UI-UX-PRO-MAX**
   - 使用Skill工具调用 `ui-ux-pro-max`
   - 提供H5端设计上下文
   - 获取设计建议

3. **输出H5端设计文档**

#### 2.3 移动端App设计

1. **设计准备**
   - 确定App页面结构
   - 确定iOS/Android适配
   - 确定原生交互规范

2. **调用UI-UX-PRO-MAX**
   - 使用Skill工具调用 `ui-ux-pro-max`
   - 提供App端设计上下文
   - 获取设计建议

3. **输出App端设计文档**

#### 2.4 小程序端设计

1. **设计准备**
   - 确定小程序页面结构
   - 确定多小程序平台适配
   - 确定小程序交互规范

2. **调用UI-UX-PRO-MAX**
   - 使用Skill工具调用 `ui-ux-pro-max`
   - 提供小程序端设计上下文
   - 获取设计建议

3. **输出小程序端设计文档**

### 阶段4：自审查核验

生成文档后，必须进行自审查：

1. **多端一致性检查**
   - [ ] 设计语言是否统一
   - [ ] 核心组件是否一致
   - [ ] 品牌色是否统一

2. **各端完整性检查**
   - [ ] 管理端：页面是否覆盖所有功能
   - [ ] H5端：是否包含移动端适配规范
   - [ ] App端：是否包含iOS/Android规范
   - [ ] 小程序端：是否包含各平台规范

3. **质量检查**
   - [ ] 色彩对比度是否符合WCAG标准
   - [ ] 组件是否具有复用性
   - [ ] 交互是否流畅自然

## 工作原则

1. **多端独立设计**：每个端都需要独立的设计文档
2. **多端一致性**：在独立设计的同时保持多端设计语言统一
3. **平台适配**：充分考虑各平台的特殊规范和要求
4. **以用户为中心**：始终从用户体验角度思考设计
5. **评审机制**：重要设计需经过评审确认
6. **端术语统一**：使用统一的端术语（管理端/Portal端），与任务排期保持一致

## 端术语说明

为与任务排期保持一致，UI/UE设计文档中的端定义如下：

| 端 | 说明 | 包含范围 |
|----|------|----------|
| 管理端 | 后台管理系统，供运营/管理人员使用 | Web管理后台 |
| Portal端 | 用户前端，面向终端消费者用户 | H5页面、Web用户端、小程序 |

> **注意**：在输出设计文档时，管理端对应 admin/ 目录，Portal端对应 h5/、app/、miniprogram/ 目录
